# Gateway & routing (Modul 7)

Base URL lokal: `http://localhost:8000` (`GATEWAY_PORT`).

## Peta route

| Prefix | Layanan | Modul |
|--------|---------|-------|
| `/api/v1/auth/**` | auth-service:8080 | 1 — Autentikasi |
| `/api/v1/catalogue/**` | catalogue-service:8081 | 2 — Katalog |
| `/api/v1/listings/**` | auction-service:8082 | 3 — Lelang |
| `/api/v1/wallet/**` | wallet-service:8083 | 4 — Dompet |
| `/api/v1/orders/**`, `/api/v1/notifications/**` | order-notification:8084 | 5 — Order & notifikasi |
| `/ws/**` | auth-service (session revoke) | 1 |
| `/ws/notifications/**` | order-notification (STOMP) | 5 |

Override URL upstream: `AUTH_SERVICE_URL`, `CATALOGUE_SERVICE_URL`, `AUCTION_SERVICE_URL`, `WALLET_SERVICE_URL`, `ORDER_SERVICE_URL` di `.env`.

## Header identitas

Setelah verifikasi JWT, gateway meneruskan:

- `X-User-Id`
- `X-User-Email`
- `X-User-Roles`

Pada `POST`/`PUT`/`PATCH` ke katalog, dompet, dan lelang, gateway mengembalikan **409** jika `sellerId` / `userId` / `bidderId` di body tidak sama dengan `X-User-Id`.

Panggilan antar layanan memakai `X-Internal-Service-Token` (`GATEWAY_INTERNAL_TOKEN`).

Detail: [adr/ADR-003-identity-gateway.md](./adr/ADR-003-identity-gateway.md).
