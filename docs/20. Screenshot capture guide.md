## Modul 3 — Auction (`bidmart-auction-service-rust`)

### Profiling before/after (samply)

```bash
cd bidmart-auction-service-rust
cargo build --release --bin profile_bidding_naive
cargo build --release --bin profile_bidding
samply record ./target/release/profile_bidding_naive   # simpan PNG ke docs/Profiling-profile_bidding_naive/
samply record ./target/release/profile_bidding         # simpan PNG ke docs/Profiling-profile_bidding_optimized/
```
