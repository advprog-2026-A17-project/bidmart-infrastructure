# Modul 8 — Monitoring & observability

Stack observability dijalankan dari `bidmart-infrastructure/docker-compose.yml` bersama layanan aplikasi.

## Komponen

| Komponen | Peran | Akses lokal |
|----------|-------|-------------|
| **Spring Actuator** | Health & metrics endpoint per layanan Java | `/actuator/health`, `/actuator/prometheus` |
| **Rust `/metrics`** | Prometheus text exposition (auction, wallet) | `/metrics` |
| **Prometheus** | Scrape interval metrics | http://localhost:9090 |
| **Grafana** | Dashboard visualisasi | http://localhost:3001 (`GRAFANA_ADMIN_USER` / `GRAFANA_ADMIN_PASSWORD`) |
| **Swagger UI** | Multi-service OpenAPI | http://localhost:8088 |

## Actuator & metrics endpoints

| Layanan | Health | Prometheus metrics | Port (compose internal) |
|---------|--------|-------------------|-------------------------|
| Gateway | `GET /actuator/health` | `GET /actuator/prometheus` | 8000 |
| Auth | `GET /actuator/health` | `GET /actuator/prometheus` | 8080 |
| Catalogue | `GET /actuator/health` | `GET /actuator/prometheus` | 8081 |
| Auction (Rust) | — | `GET /metrics` | 8082 |
| Wallet (Rust) | — | `GET /metrics` | 8083 |
| Order | `GET /actuator/health` | `GET /actuator/prometheus` | 8084 |

Konfigurasi scrape: `monitoring/prometheus/prometheus.yml`.

### `@Timed` pada critical path (Java)

| Service | Method | Metric name (Prometheus) |
|---------|--------|--------------------------|
| Auth | `POST /api/v1/auth/register` | `bidmart.auth.register` → `bidmart_auth_register_seconds_*` |
| Auth | `POST /api/v1/auth/login` | `bidmart.auth.login` → `bidmart_auth_login_seconds_*` |
| Catalogue | `POST /api/v1/catalogue/listings` | `bidmart.catalogue.create_listing` |
| Catalogue | `POST /api/v1/catalogue/listings/{id}/publish` | `bidmart.catalogue.publish_listing` |

`TimedAspect` diaktifkan via `MicrometerTimedConfig` + `spring-boot-starter-aop`.

### Wallet business counters (Rust)

`bidmart_wallet_operations_total{service="wallet",operation="hold|top_up|try_bid|payout"}` — di-increment setelah operasi sukses.

### Domain counters (Java)

| Service | Metric | When incremented |
|---------|--------|------------------|
| Auth | `bidmart_auth_login_total` | login sukses (non-2FA) |
| Auth | `bidmart_auth_register_total` | register sukses |
| Catalogue | `bidmart_catalogue_listings_created_total` | create listing sukses |
| Catalogue | `bidmart_catalogue_listings_published_total` | publish sukses |
| Order | `bidmart_orders_created_total` | order dari auction ended |
| Order | `bidmart_notifications_sent_total` | notifikasi terkirim |
| Order | `bidmart_order_rabbit_consume_total` | setiap pesan Rabbit consumed |
| Gateway | `bidmart_gateway_rejections_total{reason="unauthorized\|forbidden"}` | JWT/RBAC reject |
| Gateway | `bidmart_gateway_rate_limited_total` | HTTP 429 rate limit |

HTTP middleware mencatat `bidmart_http_requests_total`, `bidmart_http_errors_total`, histogram latency, dan APDEX (`bidmart_apdex_score`).

## Verifikasi cepat

```bash
cd bidmart-infrastructure
chmod +x scripts/verify-monitoring.sh
./scripts/verify-monitoring.sh
```

Script memeriksa health gateway (atau semua service via `USE_DOCKER=true`) dan status target Prometheus `bidmart-*`.

## PromQL contoh

**Target health (semua job BidMart):**

```promql
up{job=~"bidmart-.*"}
```

**HTTP throughput Java (auth):**

```promql
sum(rate(http_server_requests_seconds_count{application="bidmartauthservice"}[5m])) by (uri, method)
```

**Latency p95 gateway:**

```promql
histogram_quantile(
  0.95,
  sum(rate(http_server_requests_seconds_bucket{application="bidmart-infrastructure"}[5m])) by (le)
)
```

**JVM heap (catalogue):**

```promql
jvm_memory_used_bytes{application="bidmart-catalogue-service", area="heap"}
```

**Login/register timer (`@Timed`):**

```promql
rate(bidmart_auth_login_seconds_count{application="bidmartauthservice"}[5m])
rate(bidmart_auth_register_seconds_count{application="bidmartauthservice"}[5m])
```

**Wallet APDEX & operasi bisnis:**

```promql
bidmart_apdex_score{service="wallet"}
bidmart_wallet_operations_total{service="wallet"}
```

**Auction bids (Rust):**

```promql
rate(bidmart_bids_placed_total{service="auction"}[5m])
```
