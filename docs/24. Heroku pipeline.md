# Deployment topology

| Layer | Staging | Production |
|-------|---------|------------|
| Frontend | Vercel Preview (`staging` branch) | Vercel Production |
| Auth | Heroku `bidmart-auth-staging` (container) | Heroku `bidmart-auth` |
| Order | Heroku `bidmart-order-staging` (container) | Heroku `bidmart-order` |
| Catalogue, auction, wallet, gateway | VPS Compose `bidmart-staging` | VPS Compose `bidmart-prod` |
| Auth DB | Supabase `wogkzhlcliqtnbqjylkz` | same project |
| Order DB | Supabase `hcsrkmlqekuhouenbusg` | same project |
| Catalogue DB | Supabase `mekfvqtoeuwjiafltier` | same project |
| Auction DB | Supabase `begunupzsnlftbsdgmxw` | same project |
| Wallet DB | Supabase `pctktjwzbmoiftvkersb` | same project |
| Message bus | CloudAMQP (shared URL on Heroku + VPS `.env`) | same |

**No GitHub `cd.yml` for auth/order.** Deploy via Heroku Pipeline + GitHub automatic deploys (Heroku UI).

## Heroku pipelines (CLI)

```bash
heroku pipelines:info bidmart-auth
heroku pipelines:info bidmart-order
```

Apps use **container** stack + `heroku.yml` (Dockerfile build).

### Enable automatic deploys (once per app)

1. `heroku pipelines:open bidmart-auth`
2. App **bidmart-auth-staging** → **Deploy** → Connect GitHub (if needed) → enable **Automatic deploys** for branch `staging`
3. App **bidmart-auth** → enable automatic deploys for branch `staging` (promote to production via pipeline when ready)
4. Repeat for `bidmart-order` pipeline

### Config (never commit secrets)

Set on each app with `heroku config:set` — Supabase JDBC URLs, `METRICS_BASIC_*`, `AUTH_JWT_SECRET`, shared `CLOUDAMQP_URL` from `bidmart-auth-staging`.

## VPS CD (GitHub Actions)

| Workflow | Trigger | Action |
|----------|---------|--------|
| `deploy-staging-vps.yml` | push `staging` | `deploy/vps/deploy.sh staging` + edge |
| `deploy-prod-vps.yml` | push `staging` (path filter) / manual | `deploy/vps/deploy.sh prod` + edge |

Secrets: `BIDMART_SSH_PRIVATE_KEY`, optional `BIDMART_SSH_HOST`, `BIDMART_SSH_USER`, `BIDMART_SSH_PORT`.

Local:

```bash
BIDMART_SSH=bidmart BIDMART_BRANCH=staging ./deploy/vps/deploy.sh staging
BIDMART_SSH=bidmart ./deploy/vps/deploy-edge.sh
```

Env templates: `deploy/vps/env.staging.example`, `deploy/vps/env.prod.example` → `/etc/bidmart/*.env` on VPS.

## Removed / collaborator Heroku apps

Owned apps were recreated; collaborator apps were left via `heroku apps:leave`. Do not deploy catalogue/wallet/order/gateway to personal Heroku.
