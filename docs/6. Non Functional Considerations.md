# Non Functional Considerations

## Availability

- Compose `restart: unless-stopped` on all services.
- Healthchecks on databases and RabbitMQ before dependent services start.
- Gateway is single entry — scale gateway replicas requires shared Redis rate-limit state (future hardening).

## Security

- Central JWT verification at gateway (ADR-003).
- Internal tokens for service-to-service (`GATEWAY_INTERNAL_TOKEN`, per-service tokens).
- No secrets committed; use `.env` locally.

## Performance

- Load balancer URIs (`lb://service-name`) for round-robin across replicas when scaled.
- Platform APDEX and latency evidence: [12. Before after perf.md](./12. Before after perf.md).

## Operability

- Grafana admin credentials via `GRAFANA_ADMIN_USER` / `GRAFANA_ADMIN_PASSWORD`.
- Rabbit management UI on port `15672`.

## Disaster recovery

- Volume-backed Postgres data per module DB service.
- Rollback drill documented in [14. Deployment rollback.md](./14. Deployment rollback.md).
