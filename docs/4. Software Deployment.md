## Monitoring deployment

**Local (compose):**

1. `docker compose up` starts `prometheus` + `grafana`.
2. Import dashboards from `monitoring/grafana/dashboards/`.
3. Verify targets: `http://localhost:9090/targets` — all `bidmart-*` jobs **UP**.

**Production (Heroku + Grafana Cloud):**

1. Deploy backend Heroku apps; gateway last.
2. Follow [monitoring/grafana-cloud/README.md](../monitoring/grafana-cloud/README.md).
3. Scrape config reference: [monitoring/prometheus/prometheus-heroku.yml](../monitoring/prometheus/prometheus-heroku.yml).
4. `USE_HEROKU_URLS=true ./scripts/verify-monitoring.sh` before enabling cloud scrape.
