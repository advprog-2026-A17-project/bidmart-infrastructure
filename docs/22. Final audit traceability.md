## Known deployment decisions

- Official gRPC backend runtime is the VPS Compose deployment, not Heroku Common Runtime.
- Heroku remains as fallback/platform evidence for HTTP deployments and pipelines.
- Only gateway is public. Catalogue `9091` and wallet `50051` are private Compose-network ports.
- Secrets live in `/etc/bidmart/staging.env`, `/etc/bidmart/prod.env`, and `/etc/bidmart/edge.env` on the VPS. They are not committed.

## Completion gates

Run these before marking the project deployable:

```bash
# frontend
cd ../bidmart-frontend
npm run lint && npm test && npm run build

# infrastructure/gateway
cd ../bidmart-infrastructure
./gradlew clean check
./scripts/verify-grpc-private.sh
USE_DOCKER=true ./scripts/verify-monitoring.sh
node scripts/functional-smoke.mjs
```

Per-service gates:

```bash
cd ../bidmart-auth-service && ./gradlew clean check integrationTest
cd ../bidmart-catalogue-service && ./gradlew clean check
cd ../bidmart-order-and-notification-service && ./gradlew clean check
cd ../bidmart-auction-service-rust && cargo test --locked
cd ../bidmart-wallet-service-rust && cargo test --locked
```

## Git and CI gates

- Commit per repo and per subsystem using Conventional Commit messages.
- Do not add `Co-authored-by` trailers.
- Use `gh run list` and `gh run view --log-failed` until latest CI per repo is green.
- SonarCloud must be green where a scan is configured; if scan is skipped because `SONAR_TOKEN` is absent or automatic analysis is enabled, record that in evidence.
