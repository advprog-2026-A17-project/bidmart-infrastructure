# Integration verification (post-refactor)

Tanggal: 2026-05-21  
Tujuan: memastikan perubahan docs/CI/monitoring tidak memutus integrasi lintas modul.

## 1. Matriks integrasi (tidak berubah)

| Jalur | Kontrak | Token / header |
|-------|---------|----------------|
| Frontend → Gateway | `/api/v1/*` via `gatewayUrl()` | `Authorization: Bearer` |
| Gateway → Auth | `/api/v1/auth/**` | JWT validate, `X-User-Id` |
| Gateway → Catalogue | `/api/v1/catalogue/**` | RBAC listing:* |
| Gateway → Auction | `/api/v1/listings/**` | RBAC bid/auction |
| Gateway → Wallet | `/api/v1/wallet/**` | JWT + internal untuk hold |
| Gateway → Order | `/api/v1/orders/**`, `/api/v1/notifications/**` | JWT |
| Order → Auth (internal) | `GET /api/v1/auth/internal/users/{id}/profile` | `X-Internal-Service-Token` |
| Order → Wallet | hold/release/convert | `x-internal-service-token` |
| Auction → Wallet | hold on bid | `GATEWAY_INTERNAL_TOKEN` |
| STOMP notifikasi | `/ws/notifications` via gateway | JWT (`bidmart.auth.jwt-secret` sama) |

Compose: `BIDMART_AUTH_BASE_URL=http://auth-service:8080`, `GATEWAY_INTERNAL_TOKEN=bidmart-local-internal-token` — selaras di semua service.

## 4. Perubahan terbaru vs integrasi

| Perubahan | Dampak integrasi |
|-----------|------------------|
| Wallet metrics middleware | Hanya `/metrics` + HTTP layer; API `/api/v1/wallet/*` tidak berubah |
| Order deps (mail, jjwt, webpush) | Prod: SMTP/WebPush; lokal/test: profile `local` → log senders |
| `fetchUserEmail` + `notifyUserDisabled` | Melengkapi Order ↔ Auth event `UserDisabled` |
| Gateway `admin/close` permission | `POST .../admin/close` → `admin:users` (selaras katalog) |
| CI all branches | Tidak mengubah runtime |
| History rewrite git | Tidak mengubah kode runtime |

## 5. Kesimpulan

- **Backend 6 modul + gateway**: terintegrasi; unit test hijau.
- **Frontend**: masih memanggil path gateway yang sama; satu test kontrak perlu update jika `SellPage` tidak lagi mengirim `auctionType`.
- **E2E penuh**: jalankan `functional-smoke.mjs` dengan stack Docker untuk bukti 100% runtime.
