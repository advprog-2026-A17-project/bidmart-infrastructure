| Perubahan | Dampak |
|-----------|--------|
| `AUTH_WALLET_PROVISIONING_EXCHANGE=bidmart.wallet.provisioning` | Auth publish ↔ wallet consumer selaras |
| Wallet `metrics.rs` wired (middleware + `/metrics` + domain counters) | Observability parity auction; tidak mengubah API |
