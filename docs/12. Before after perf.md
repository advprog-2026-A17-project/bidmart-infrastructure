- Tool: `cargo test profiling -- --nocapture` + `cargo bench` (criterion)

## 3. Optimized (After)

### 3.1 Commit / Tag optimized
- Commit hash/tag: `git rev-parse HEAD` di repo auction (lihat `bidmart-auction-service-rust`)
- Tanggal run: `2026-05-21`
- Artifact raw log/file: sama — `profile_bidding_comparison_tests.rs` + samply di [`docs/Profiling-profile_bidding_optimized/`](../../bidmart-auction-service-rust/docs/Profiling-profile_bidding_optimized/)

### 3.2 Optimized Implementation Details
- Status tracking: `enum ListingAuctionSessionStatus` → zero-cost comparison (single integer cmp)
- Bid tracking: `Option<Bid>` → O(1) direct field access
- Value types: `Money(u64)`, `UnixSeconds(u64)` → stack-allocated newtypes
- Anti-sniping: enum mutation → no allocation
- Concurrency: per-auction mutex lock → fine-grained concurrency

#### Sequential Bid Placement (100 bids × 1000 iterations) — measured 2026-05-21:
- After total time: `17,397 µs` (**96.5%** faster vs naive)
- Per-bid (optimized): `~173 ns`
- Complexity per bid: `O(1)` lookup → O(n) total

#### samply microbench (10k × 200 bids):
- After: **127 ms** total, **63 ns**/bid — **97.6%** improvement (41.6×)

## 7. Optimization Techniques Summary

### 7.1 Algorithmic: O(n) → O(1)
```diff
- // Before: Linear scan over ALL bids every time
- let current_highest = self.bids.iter().cloned().max_by_key(|b| b.amount_cents);

+ // After: Direct O(1) field access
+ match &self.current_highest {
+     Some(bid) => bid.amount + self.minimum_increment,
+     None => self.starting_price,
+ }
```

### 7.2 Type-Level: String → Enum
```diff
- // Before: Heap-allocated String comparison
- if self.status != "ACTIVE" && self.status != "EXTENDED" {

+ // After: Zero-cost enum comparison (single integer cmp)
+ if self.status != ListingAuctionSessionStatus::Active
+     && self.status != ListingAuctionSessionStatus::Extended {
```

### 7.3 Value Objects: Raw Primitives → Newtypes
```diff
- // Before: Ambiguous raw u64
- pub fn place_bid(&mut self, bidder_id: &str, amount_cents: u64, now: u64)

+ // After: Type-safe, stack-allocated newtypes
+ pub fn place_bid(&mut self, bidder_id: UserId, amount: Money, now: UnixSeconds)
```

### 7.4 Concurrency: Per-Auction Fine-Grained Locking
```rust
// No global lock — each auction has its own Mutex
bid_locks: Arc<Mutex<HashMap<String, Arc<tokio::sync::Mutex<()>>>>>
```

### 7.5 Database: Optimistic Concurrent Update
```sql
UPDATE listings
SET current_highest_bid_cents = $1
WHERE id = $5 AND (current_highest_bid_cents IS NULL OR current_highest_bid_cents < $6)
```
